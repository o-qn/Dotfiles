# Personal LazyVim

Python: BasedPyright + Ruff; JSON: schemas; CSS: validation + Prettier.
Text and Markdown wrap with spell checking; prose is not reformatted on save.

`Space c f`: format · `Space c v`: Python environment · `Space c p`: run Python.
`Space u f`: toggle formatting · `]s`/`[s`: spelling errors · `z=`: suggestions.

Noctalia generates `lua/noctalia_palette.lua`. Open editors follow palette changes automatically.
Requires Node.js, Python 3 and LazyVim’s normal dependencies. Language tools install through Mason.
