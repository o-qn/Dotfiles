# Zen theme

Based on [Noctalia community templates](https://github.com/noctalia-dev/community-templates/tree/f809cda2207e1dd8d86d03fab4b2198c3c9c4035/zen-browser).

Uses Noctalia’s active palette and mode, keeps Zen opaque, and limits content styling to browser pages.
`apply.py` adds imports and enables custom stylesheets while preserving existing mods and preferences.
Restart Zen after applying or changing the palette.
